# Project description

Exercise 5 is a team project. Teams choose their own dataset and use case. The technical path is the same one practiced in Exercises 1–4.

## What every team builds

1. Dataset preparation
2. Training pipeline
3. Model evaluation
4. Improvement iteration
5. Model deployment
6. Tool/API integration
7. GenAI application
8. End-to-end workflow

## Target shape

```text
User
  ↓
GenAI application
  ↓
Prediction tool
  ↓
Deployed ML model
  ↓
Prediction result
  ↓
Generated response
```

Teams also show an improvement loop: version 1, measurement, improvement, re-measurement.
